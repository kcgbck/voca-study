## 구현과 안전 경계

- 같은 질문의 실제 AI 결과가 `relevant && sentenceComplete === true`일 때만 답변 원문과 평가 사본을 컨트롤러 메모리 한 칸에 보관한다.
- 반복 단계에서만 질문 ID와 양 끝 공백을 제외한 문자열이 정확히 일치하면 재사용한다. 대소문자·문장부호·단어 변경도 새 평가 대상이다. 예문 자체, 단답형, 오답, 불확실한 답변, 실패한 요청은 정답 캐시를 만들지 않는다.
- 새 학습 시작·같은 질문 재시작·일시정지 시 초기화한다. 취소된 이전 응답이 새 학습에 들어오지 않는다. 영구 저장·서버 학습 기록 저장은 없다.
- 첫 답변과 달라진 답변은 계속 AI 평가한다. 재사용은 실제 최종 음성 결과 또는 텍스트 제출 후에만 작동하며, 마이크 10초 창이나 중간 인식 결과를 건너뛰지 않는다.
- 재사용 시 HTTP 요청·요청 ID 생성·예산 예약·차감·분당 한도 대기가 모두 없다. 기존 한국어 피드백과 1회/2회 반복 횟수 규칙은 유지한다.
- 초보 답변의 의미와 문법 완성도를 분리한다. 알아들을 수 있는 문법 오류는 의미를 인정하면서 완전한 문장으로 교정하고, 알 수 없는 발화는 `uncertain`으로 멈춘다. 이름·음료·나이·부정 표현을 교재 답안에 맞춰 바꾸지 않도록 지시한다.

- 불완전·불확실·문장 형태만 완전한 오답의 무크레딧, 질문 변경과 재시작, pause 후 텍스트 제출, 이전 비동기 응답의 오염 방지.

기존 시험 중 매번 AI를 호출한다는 기대값은 사용자 승인된 새 동작으로 바꿨다. 불확실한 반복·분당 한도 시험은 **달라진 답변**을 입력하여 실제 평가와 차단 경계를 계속 검사한다. 마이크 수집 횟수·정답 횟수·잘못된 답변 차단 조건은 유지했다.

## 실제 운영 API + 컨트롤러 시험

`.agy-work/205_repeat_live.ts`는 실제 컨트롤러·클라이언트·운영 API를 연결한다. 마이크와 스피커만 합성 입력/무음 대역이다. **S25 실기기 발음 시험이 아니다.**

| 흐름 | 최종 입력 횟수 | AI 요청 | 추가 차감 없는 반복 |
|---|---:|---:|---:|
| My name is Alex. → 동일 문장 | 2 | 1 | 1 |
| My name is Alex. → My name is Mina. | 2 | 2 | 0 |
| Coffee, please. → I'd like a coffee, please. → 동일 문장 | 3 | 2 | 1 |
| 합계 | 7 | 5 | 2 |

3개 흐름 모두 완료되었고 예상 횟수와 일치했다. 실제 API 요청은 1.445~12.445초. 재사용 시 로컬 제어 흐름의 피드백 전달은 0.01~0.03ms였으나 이는 모의 마이크·무음 출력 환경의 측정으로, 실제 휴대폰 발화 완료·음성 재생 시간은 포함하지 않는다. 사용자가 체감하는 이득은 **반복 시 추가 AI 네트워크 대기를 생략**하는 것이다.

## 음성 이해의 현실적인 범위

이번 개선은 브라우저가 인식한 최종 텍스트의 **의미 해석과 피드백**을 강화한다. Web Speech 음성 인식 모델 자체를 재학습한 것은 아니다. [MDN의 phrases 설명](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/phrases)은 문맥 힌트를 실험 기능으로 표시한다. S25 지원이 확인되지 않은 기능을 강제로 켜거나 정답 예문 쪽으로 인식을 편향시키는 변경은 하지 않았다. 10초 수집, 영어 설정, 중복 제거, 원본 최종 결과만 평가하는 기존 경계는 유지한다.

6개 합성 문장만으로 실제 초보 발음의 인식률 향상을 확정하지 않는다. S25 Chrome에서 실제 발음·소음·망 상태가 포함된 확인은 별도로 남는다.

## S25 확인 순서

1. Chrome에서 최종 운영 주소를 새로고침한다. 음성 듣기는 기존 10초다.
2. 첫 영어 질문에 완전한 문장으로 답한다. 첫 평가는 기존처럼 AI 응답을 기다린다.
3. 따라 말하기에서 화면에 인식된 문장과 정확히 같은 문장을 다시 말한다. 최종 인식이 확정된 뒤 추가 AI 분석 대기 없이 피드백/완료로 진행해야 한다.
4. 다른 단어로 말하면 새 AI 평가가 필요하다. 음성 인식기가 대소문자나 문장부호까지 달리 반환한 경우에도 보수적으로 새 평가를 사용하므로, 비슷한 발음이면 항상 재사용되는 것은 아니다.
5. 브라우저에서 실제로 잘못 인식된 사례가 남으면 말한 문장과 표시된 문장을 비교해 추가로 점검한다. 이번 합성·텍스트 검증을 실제 발음 인식률 검증으로 대신하지 않는다.
