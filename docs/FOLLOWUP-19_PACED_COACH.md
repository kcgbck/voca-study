# FOLLOWUP-19 — 개인 3 RPM 제한 제거와 답변 보관 대기

2026-10-23. Gemini 구독 CLI가 제품 코드를 구현하고 Codex가 지시·독립 시험·검토를 담당했다. FOLLOWUP-18에 기록된 개인/IP 3 RPM은 이번 변경으로 대체한다.

## 사용자에게 달라지는 동작

- 공개 초급 코치의 `min(callerRpm, 3)` 강제 제한을 `min(callerRpm, rpm)`으로 변경했다. 현재 운영 설정에서는 같은 사용자가 전체 잔여 한도 내에서 분당 최대 13회 평가를 요청할 수 있다.
- 모든 사용자가 공유하는 90% 안전 한도는 CHAT 13 RPM / 225,000 로컬 안전 계량 유닛 TPM / 450 RPD로 유지한다. 더 작은 운영 설정은 그대로 존중한다.
- 서버가 Gemini 호출 전에 로컬 분당 한도로 거절한 경우에만 답변을 보관하고 61초 카운트다운 뒤 자동 재평가한다. 반복 연습 중에도 같은 답변과 진행 횟수를 보관한다. 기다리는 동안 마이크를 다시 켜거나 답변을 제출할 필요가 없다.
- 자동 대기는 최대 2회다. 일일 소진, 중복 요청, 예산 DB 진단 실패, Gemini 429/503, 네트워크 오류·시간 초과는 자동 재시도하지 않는다. 외부 호출 여부가 불확실한 오류를 재전송해 사용량을 중복 소모하지 않도록 한다.
- 일시정지, 다음 학습 시작, 페이지 이탈, 컴포넌트 해제 시 기존 대기를 취소한다. 대기 중 입력 및 제출을 막는다.
- 질문→6초 영어 입력→한국어 피드백/영어 예문→정답 1회·교정 2회 반복→다음 흐름, 확인 질문 제거, 성인 확인 1회 저장은 유지한다.

## 사용량 해석

브라우저 음성 인식과 읽기는 Gemini STT/TTS API를 호출하지 않는다. 다만 Chrome 음성 인식은 네트워크를 사용할 수 있으므로 오프라인 보장은 아니다. 인식된 영어를 AI가 평가할 때 CHAT API가 사용되며, 반복 연습 평가도 각각 1회다. 질문 하나를 최초 평가+반복 1~2회로 마치면 보통 2~3회 평가가 필요하고, 추가 재답변·재연습은 더 소모한다. 450회는 질문 450개를 뜻하지 않는다.

로컬 분당 거절 및 카운트다운은 Gemini 호출·예산 예약 증가가 없다. 대기 후 원자적 예약에 성공해 실제로 호출하는 평가만 차감한다. 이미 외부 호출한 실패는 보수적으로 차감을 유지한다. TPM 유닛은 실제 Google 청구 토큰 수가 아니라 기존 안전 추정값이다. 이 변경은 무료 총량을 늘리거나 다른 프로젝트의 사용량까지 통합 추적하는 기능이 아니다.
