2026-10-23 KST. 사용자는 운영 메인 주소 `voca-study-akf.pages.dev`에서 새 음성 검사 버튼이 보이지 않는다고 보고했다. 배포 번호가 붙은 이전 버전 주소는 아니라고 확인했다.

## 근거와 수정

- Cloudflare 배포 이력에서 `462e0e84`가 Production/main 최신 배포임을 읽기 전용으로 확인했다. Git push가 없어도 직접 배포는 완료된 상태였다.
- `public/sw.js` v6는 HTML 탐색에도 캐시를 먼저 반환했다. 실제 서비스 워커 코드를 VM에서 실행한 회귀시험에서 온라인 최신 HTML 대신 `CACHED_OLD` 반환을 재현했다.
- 새 버튼은 회화 홈에만 있고 기존 앱은 수업 위치를 복원한다. 운영 브라우저에서도 저장 수업→커리큘럼→회화 홈으로 이동한 뒤에야 버튼을 찾았다. 사용자 휴대폰에서 두 원인 중 어느 쪽이 발생했는지는 직접 단정하지 않는다.
- Gemini가 v7로 올리고 HTML 탐색에 네트워크 우선·5초 상한·오프라인 캐시 폴백을 적용했다. HTTP 거부 응답과 리다이렉트는 HTML 캐시에 기록하지 않는다. 구버전 정리는 이 앱의 캐시 접두사만 대상으로 한다. IndexedDB와 localStorage는 삭제하지 않는다.
- Gemini가 `src/main.tsx`에 `?voice-check=1` 직접 진입을 추가했다. App의 저장 탭·수업 복원을 거치지 않고 검사 화면을 렌더하며 `음성 연결 v1`을 표시한다. 반환 버튼은 기본 앱으로 돌아간다.
