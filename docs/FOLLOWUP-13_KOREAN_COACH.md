## 사용자 확인과 목표
- S25 Edge의 Chrome 앱에서 질문 음성 출력과 영어 음성 인식이 작동함을 사용자가 확인했다. 인앱 브라우저에서는 출력 실패를 보고했다.
- 실제 학습은 영어 질문·영어 답변과 한국어 진행·피드백으로 구성한다.
- 로그인 제거, 성인 대상 체크 1개. 무료 브라우저 음성을 기본으로 사용한다.
- 한 질문의 답변 평가 후 맞으면 1회, 교정이 필요하면 2회 반복한다. 완료 후 다음 버튼을 누를 때만 다음 질문을 시작한다.
- 질문 후 생각 10초와 답변 창 최대 45초. 인식 문장을 화면에 보여 주고 한국어 네/아니요 음성 확인 후에만 AI에 보낸다.

## 역할과 검증 진행
- Gemini 구독 CLI가 제품 구현을 담당하며 Codex는 범위 지정·테스트·검증을 담당한다.
- 초기 컨트롤러에서 음성 실패 무시, TTS 무기한 대기, 취소 불응 네이티브 대기, 답변 시간 상한 미작동을 테스트로 재현했다. 실패를 숨기지 않고 Gemini에 수정 지시했다.
- 공개 전용 API는 기존 독립 예산 DB와 모델별 90% 상한을 재사용한다. 확인된 영어 텍스트만 처리하고 사용자 발화나 음성을 DB에 저장하지 않는다.
- 기존 인증 API의 보호를 일괄 해제하지 않는다. 새 공개 경로는 성인 확인과 예산 검사를 별도로 수행한다.
