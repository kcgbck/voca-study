# FOLLOWUP-21: 10초 음성 입력과 평가 지연 검증

2026-10-23. Gemini 구현, Codex 지시·독립 검증. 무료 프로젝트, 기존 모델과 전체 90% 예산 유지.

## 원인과 변경 범위

- 음성 입력은 인식기 준비 시점부터 정해진 창 전체를 사용한다. 초보자의 문장 중간 멈춤을 잘라내지 않도록 기본 창을 6초에서 10초로 늘렸다. 따라서 이 변경 자체가 평가 시작을 앞당기지는 않는다.
- 그 뒤 별도의 Gemini 평가 요청이 발생한다. 기존 운영 경로의 합성 문장 순차 측정에서 정상 3건은 9.372~10.210초, 무의미 발화 1건은 20.120초에 시간 초과했다. 마이크가 아닌 평가 HTTP 요청만 측정한 값이다.
- 평가 프롬프트를 압축하고 한국어 피드백을 짧은 한 문장으로 요청한다. 자연어 의미 평가, 단답형과 완전 문장 구분, 불확실한 인식의 진도 차단, 사용자 의도 보존을 유지한다.
- `maxOutputTokens` 512, `thinkingConfig.thinkingLevel` minimal을 명시한다. [Google 공식 문서](https://ai.google.dev/gemini-api/docs/generate-content/thinking)에 따르면 3.5 Flash-Lite의 기본값도 minimal이다. 따라서 기본 깊은 추론이 지연의 원인이었다거나 이 설정만으로 속도가 개선된다고 주장하지 않는다. 출력 상한은 속도를 보장하지 않으며 응답 잘림 여부도 실제 시험한다.
- 모델 교체, 유료 호출, 중복 병렬 호출, 정답 추측, 예산 완화는 하지 않았다. 텍스트 모드는 시간 제한 없는 대기를 유지한다.

## 독립 검증

- 변경 전 새 회귀시험: 기본 창 10000ms 및 짧은 생성 설정 기대값 2건 실패를 확인했다.
- 10초 창에서 8초 이후 시작하고 9.5초에 완성된 답변을 정상 수집한다. 중간 결과는 평가하지 않으며 마지막 결과만 평가한다.
- 기존 명시적 6초 옵션 시험은 보존한다. 기본값을 사용하는 실제 음성 서비스 통합 시험만 10초로 갱신한다.

## 남은 개선 후보와 기기 확인

- 실제 S25 Chrome에서 새로고침 후 10초 안내를 확인하고, 질문 종료 뒤 7~8초쯤 생각한 다음 짧은 영어 답변을 말해 문장이 끝까지 들어오는지 확인한다. 10초 입력 창 종료 후 평가 HTTP 시간이 별도로 필요하다.
- 무료 범위에서 다음 효과가 큰 후보는 **동일 질문에서 이미 AI가 완전한 정답으로 검증한 동일 문장의 반복 연습에 한해 직전 평가를 재사용**하는 것이다. 첫 답변·다른 단어·불확실한 답변은 계속 AI 평가하며, 고정 예문과 비슷하다는 이유로 정답 처리해서는 안 된다. 이번 변경에는 이 기능을 포함하지 않았다.
- 긴 초기 평가의 원인을 더 세분화하려면 예산 처리/Google 요청의 구간별 시간을 측정해야 한다. 현재 수치는 전체 평가 HTTP 시간이며 Google 내부 추론 시간 자체의 직접 측정은 아니다.
- S25 실기기 음성 품질·장시간 사용, PWA/iOS, 기존 커리큘럼 사람 검토, 보드의 기존 자료 미제공 항목은 이번 자동 검사로 완료 처리하지 않는다.
