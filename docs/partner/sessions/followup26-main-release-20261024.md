FOLLOWUP-26: 사용자가 전체 개발 변경 보존·커밋·main 푸시와 단일 기본 주소 운영을 승인했다. Gemini가 별도 회화 React 진입점을 제거하고 App 홈으로 통합, 오래된 시험 쿼리 제거, SW v8 및 갱신 확인을 구현했다. Codex는 진입점 및 SW 비파괴 업데이트 시험을 추가하고 75파일 729시험을 검증했다. 기존 회화/예산/백업 개발 결과와 문서를 함께 보존한다. 커밋 전 전체 원본을 기록하고 검증한 경로만 어댑터로 커밋한다. 푸시 후 직접 업로드 방식 Pages에도 동일 코드를 배포하고 새 메인을 확인한 뒤 과거 배포를 정리한다. 실제 기기·사람 검수 관문은 완료로 바꾸지 않는다.
