## 비교 조건과 증거

- Gemini가 일회성 비교 도구 `.agy-work/025_model_compare.ts`를 작성하고 Codex가 검토·교정 지시·실행·결과 검증을 담당했다. 시각 차이로 요청 해시가 달랐던 초기 초안과 모델 목록을 모두 읽은 후 크기를 검사하던 부분을 Gemini가 수정했다.
- 공식 [Google 가격표](https://ai.google.dev/gemini-api/docs/pricing)에서 세 모델의 Standard 무료 입력·출력을 확인했다. 프로젝트 청구 미연결은 사용자 확인에 근거하며 이번 도구가 청구 상태를 독립 조회한 것은 아니다.
- 모델 목록 GET1회에서 세 요청 모델의 존재와 `generateContent` 지원 확인, 추가 페이지 없음. 생성 요청은 순차6회(입문 정순·고급 역순), 모델/수업당1회, 자동 재시도0. 이 실행을 재시도하지 않았다.
- 실제 수업 코드가 생성한 입문4,215바이트·고급5,061바이트 요청을 사용했다. 각 수업의 세 모델 요청은 SHA256 동일. 서버20초, LOW thinking, 출력 최대1,024토큰 조건을 유지했다.
- 격리된 합성 인증·예산 어댑터를 사용했다. 운영 Access·D1 연동 실사용 시험이 아니다. 사용자 사진·PDF·음성·학습 기록 전송0. 키는 실행 중 메모리와 요청 헤더에서만 사용하고 앱/환경 파일을 변경하지 않았다.
- `vite-node .agy-work/025_model_compare.ts --dry-run`: 모의6/6 통과, 실제 네트워크0. 잘못된 옵션 및 dry/live 충돌: 예상 exit1로 호출 전 종료. 실제 비교 명령은 `vite-node .agy-work/025_model_compare.ts --live`이며 완료 exit0은 보고서 기록 완료를 뜻하고 모델 전체 통과가 아니다.
- 실제 결과 `.agy-work/025_model_compare_live.json`, 무호출 결과 `025_model_compare_dry.json`, Codex 단언 검증 `025_supervisor_verification.json`. 기존 앱·시험·스크립트·의존성167파일 해시 불변. 실제 제공 키 값의 소스·문서·빌드 복제 검사와 `git diff --check` 통과.
- 제품 소스 변화가 없으므로 이전 전체51파일462시험·Pages9/9 결과는 FOLLOWUP-02의 검증 이력으로 유지하며 이번에 다시 실행했다고 주장하지 않는다. 보드 생성물도 이번 비교에서 변경하지 않았다.
