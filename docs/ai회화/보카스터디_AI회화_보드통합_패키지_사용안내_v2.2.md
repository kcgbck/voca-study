# 보카 스터디 — AI 회화 + 알고리즘 보드 통합 개발 패키지 v2.2 사용 안내

## 1. 이번 버전의 의미

**이 v2.2 지시서 하나가 이전 v2.1 ‘회화 1차 개발 지시서’를 대체한다.** 이전 지시서와 v2.2를 따로 한 번씩 실행하지 않는다. 이미 v2.1 작업 중이라면 완료한 코드를 보존하고 이 지시서의 보드 보강 항목만 포함시켜 같은 통합 작업을 마무리한다.

범위: **회화 기능 구현 + 128차시 교육과정 틀 + 초기 32차시 내용 초안 + 무료 구글 API 안전 연동 + 기존 앱 구조 최소 보강 + 알고리즘 보드 HTML/MD 동시 증분 확장 + 검증 + 결과 보고**.

## 2. 압축 패키지 포함 항목

1. **`보카스터디_AI회화_보드통합_1차개발지시서_v2.2.md`** — **Codex에게 실행시킬 단일 메인 지시서**. 먼저 읽어야 하는 파일.
2. `보카스터디_AI회화_통합개발계획_v2.2.md` — 전체 128차시/아키텍처/교육·보안 기준, 보드 통합 범위 포함.
3. `보카스터디_알고리즘보드_보강규격_부록_v2.2.md` — 27개 신규 노드, 3개 추가 탭, 오류 경로·실제 연결선, 12개 보드 전용 검증 관문 명세.
4. `references/사용자제공_알고리즘보드_기준본.html` — 사용자가 업로드한 보드 HTML **읽기 전용 비교본**.
5. `references/사용자제공_알고리즘보드_기준본.md` — 사용자가 업로드한 보드 MD **읽기 전용 비교본**.

## 3. Codex에 전달하는 방법

- 현재 보카 스터디 프로젝트를 Codex에서 연다.
- ZIP을 풀고 1~3번의 MD 파일 및 필요시 `references/` 폴더를 첨부한다.
- **참조용 HTML/MD를 기존 프로젝트의 실제 `docs/` 보드 파일 위에 덮어쓰지 않는다.** Codex가 로컬 최신본과 비교만 하도록 한다.
- 아래 문장을 Codex 세션에 그대로 보낸다.

```text
[보카 스터디 AI 회화 + 알고리즘 보드 통합 개발 실행]

보카스터디_AI회화_보드통합_1차개발지시서_v2.2.md를 단일 실행 지시로 삼고,
보카스터디_AI회화_통합개발계획_v2.2.md와
보카스터디_알고리즘보드_보강규격_부록_v2.2.md를 상세 기준으로 적용해라.

사용자 제공 알고리즘 보드 HTML/MD는 읽기 전용 원본 비교 자료다.
현재 로컬 작업 트리와 최신 docs 보드를 먼저 확인하고 기존 변경을 전부 보존하라.

기존 1차 회화 기능 구현과 알고리즘 보드의 정확성 보강·신규 AI 회화 노드·간선 추가를
한 번의 통합 작업으로 끝내라. 준비→구현→시험→결함 수정→재시험→통합 보고까지 진행한다.
이미 수행 중인 v2.1 구현은 재시작·중복 수행하지 말고 이 지시를 이어서 통합한다.

운영 배포, 실서비스 DB 변경·삭제, 유료 API 호출, Git 커밋·푸시는 승인되지 않았다.
실제 계정/기기 등 외부 의존 항목은 미검증을 정확히 기록하고 나머지 개발은 계속하라.

최종 결과를 반드시
[보카 스터디 AI 회화·보드 INTEGRATED-01 통합 작업 결과]
형식으로 출력해라. 내가 ChatGPT에 전체 내용을 붙여넣어 독립 검토받겠다.
```

## 4. 완료 확인 포인트

- 회화 기능은 기존 앱 데이터를 해치지 않는 로컬 구현·자동시험 결과가 있어야 한다.
- 보드는 신규 코드의 실제 상태를 반영해야 하며, 원본 카드와 ID가 누락되면 안 된다.
- 두 보드 파일 HTML/MD의 ID, 상태, 15항목, 연결 경로, 검증 근거가 정합해야 한다.
- 신규 보드 목표는 사용자 제공 기준선에서는 18탭·125노드. **기존 로컬의 최신 상태가 다르면 이 숫자에 억지로 맞추지 않는다.**
- `BOARD-01`~`BOARD-12`, `LOCAL_INTEGRATION_STATUS`, `BOARD_STATUS`, `COMBINED_STATUS`의 시험 근거를 확인한다.
- Gemini 실제 이용량, 기기 실측, 사람 검수, 운영 공개는 미검증이면 미검증이라고 적는다.

## 5. 사용자와 ChatGPT의 후속 작업

Codex가 출력한 `[보카 스터디 AI 회화·보드 INTEGRATED-01 통합 작업 결과]`를 이 대화에 **전체 그대로** 붙여넣는다. ChatGPT는 구현 AI와 독립된 검토자로서 완료 근거·보드 정합성·누락 시험·보류 관문을 검토하고 **진짜 남은 작업만 묶어** 다음 지시서를 제시한다.
