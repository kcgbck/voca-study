# FOLLOWUP-20 — S25 Chrome 확인 순서와 남은 검증

2026-10-23. Gemini가 제품 코드·보드 설명을 구현하고 Codex가 재현 시험·검토·브라우저 검증을 담당한다.

## 휴대폰 확인 순서

1. S25 Edge의 Chrome 앱에서 `https://voca-study-akf.pages.dev/?voice-check=1&build=20261023-9`를 열고 새로고침한다. 제목은 ‘AI 영어 회화 (초급)’, 시작 버튼은 ‘코칭 시작’이다. 옛 ‘음성 연결 확인’ 화면이면 새 주소를 Chrome 주소창에 직접 넣는다. 이전에 성인 확인을 저장한 같은 브라우저에서는 체크박스가 없어야 한다. 새 브라우저·사이트 데이터 삭제 후에는 다시 확인해야 한다.
2. 코칭 시작. 한국어 상황 안내 뒤 영어 질문이 나온다. ‘6초 동안 듣는 중’에 영어로 대답한다. 마이크를 매번 누르거나 ‘네’라고 확인할 필요가 없다. 분석 중에는 같은 답을 다시 말하지 말고 기다린다.
3. 첫 질문 `What is your name?` → `My name is Alex.`. 화면의 인식 문장이 맞고, 한국어 피드백 및 영어 모범 답안이 이어지는지 확인한다. 모범 답안을 듣고 마이크가 자동으로 켜지면 따라 말한다. 완전한 답변이면 반복 1회 완료 뒤 ‘다음 질문으로’가 나온다.
4. 다음 → `How old are you?` → `I am twenty years old.`. 가상 나이로 연습한다. 반복 1회 후 다음으로 간다.
5. 세 번째 `What would you like to drink?` → `Coffee, please.`. 주문 뜻을 이해하면서 더 완전한 문장(예: `I would like a coffee, please.`)을 한국어로 제안해야 한다. 무조건 틀렸다고 처리하거나 설명 없이 정답 통과하면 기록한다. 제안된 영어 예문을 2회 따라 말해 2/2 완료를 확인한다. 모델 문구는 매번 달라도 된다.
6. 가능하면 아침 질문에는 `I had toast.`, 취미 질문에는 `I like listening to music.`로 답한다. 각각 안내된 반복을 마치고 마지막에 ‘연습 마치기’→‘오늘 연습을 마쳤어요’가 나오며 더 이상 자동 질문·마이크가 시작되지 않는지 확인한다.
7. 나갔다 돌아오거나 새로고침해 성인 체크가 다시 나타나지 않는지 확인한다. 선택 시험: 질문 중 일시정지를 누르면 소리·마이크가 멈춰야 한다. ‘다시 시작’은 현재 질문을 처음부터 다시 시작하는 동작이다.

결과는 `한국어 안내 O/X, 인식 O/X, 확인 질문 없음 O/X, 정답 반복 1회 O/X, 단답 교정 반복 2회 O/X, 마지막 종료 O/X, 성인 체크 숨김 O/X`처럼 간단히 적으면 된다. 실패 시 몇 번째 질문·말한 영어·화면에 나온 영어·오류 문구만 남긴다. 기본적으로 진단 JSON을 요구하지 않는다. 개인 이름·실제 나이·민감정보는 시험에 필요하지 않다.

분당 한도를 채우는 시험은 하지 않는다. 우연히 ‘잠시 대기 중’이 나오면 답변이 그대로 남고 카운트다운 후 자동 평가되는지만 확인한다. 하루 한도 종료는 기다리면 즉시 풀리는 분당 대기와 다르다.

## 이번에 재현한 남은 결함과 수정

- 텍스트 전환 직후 시작 전 제출 시 입력만 지워지는 문제: 첫 학습 시작 전 입력·제출 차단, 내부 제출 처리도 시작 여부 검사.
- 텍스트를 기다리는 동안 음성 준비·6초·무음 재시도 제한이 작동하는 문제: 별도 취소 가능한 텍스트 대기로 분리. 타이머·마이크 없이 입력을 기다린다.
- 음성 인식 및 말하기 안내가 텍스트 화면에 남는 문제: 텍스트 입력 대기/제출 답변 안내로 변경.
