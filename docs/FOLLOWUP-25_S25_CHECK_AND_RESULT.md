## S25 확인 순서

1. **Chrome 앱**에서 [현재 버전](https://voca-study-akf.pages.dev/?voice-check=1&build=20261024-1)을 열고 새로고침 → `코칭 시작`을 누른다. 성인 확인은 사이트 저장소가 유지되면 다시 나오지 않는다.
2. 이름 질문에 `My name is Alex.`라고 말한다. 첫 답변은 AI가 평가한다. 한국어 안내 후 같은 문장을 다시 말하면 10초 듣기와 최종 인식 확정 후 **추가 AI 분석 대기 없이 1/1 완료**되어야 한다. 피드백 음성 재생 시간은 남는다. 중간에 일시정지·다른 앱 전환·재시작은 하지 않는다.
3. `다음`에서 나이 질문에 `I am twenty-eight years old.`라고 답하고 반복한다. 실제 나이가 28로 인식되는지 본다. `28`과 `twenty-eight`는 아직 별도 비교이므로 표기가 바뀌면 다시 평가하는 것이 정상이다.
4. 음료 질문에 `Coffee, please.`라고 답한다. 한국어로 완전한 문장을 권하면 **실제 화면 예문**을 두 번 반복한다. 첫 완전 문장은 AI 평가, 두 번째 같은 완전 문장은 추가 평가 생략 후 2/2 완료가 기대 동작이다.

말하면서 대소문자·문장부호를 지정할 수는 없다. 이번 수정 자체를 확실하게 확인하고 싶으면 학습을 끝낸 뒤 같은 링크를 다시 열어 **텍스트 모드로 전환 → 코칭 시작 → `My name is Alex.` 제출 → 반복 칸에 `MY NAME IS ALEX!` 제출**한다. 이 경우 추가 AI 분석 없이 1/1 완료되어야 한다. 별도로 새 학습을 시작해 첫 답변 Alex, 반복 답변 `My name is Mina.`를 제출하면 새 AI 평가를 거쳐 Mina로 피드백/예문이 갱신되어야 한다.

문제가 있으면 `말한 문장 / 최종 표시 문장 / 반복에서 AI 분석 대기가 있었는지`만 우선 전달한다. 내부 쉼표·소수점·하이픈·아포스트로피 유무, 단어·숫자·부정 표현이 바뀐 경우는 재평가 대상이다. 숫자 단어 치환·축약형 확장까지 같은 정답으로 추정하지 않는다.
