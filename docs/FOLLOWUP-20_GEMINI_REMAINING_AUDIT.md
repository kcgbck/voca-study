## 1. 현재 공개 코치 (2026-10-23) 배포 및 검증 완료 항목

1. **무로그인 5개 핵심 일상 질문 코치 운영**:
   - 질문 5종: `name`, `age`, `cafe`, `breakfast`, `hobby`
   - 성인 18세 이상 확인 체크박스는 같은 브라우저의 사이트 저장소가 유지되는 동안 저장(삭제/비공개 모드/저장 차단 시 재확인 가능)(`coach_adult_confirmed_coach-2026-10-23`)되며, 체크 즉시 및 재방문 시 화면에서 완전히 숨김 처리됨.

2. **직접 평가(Direct Evaluation) 흐름 전환 (FOLLOWUP-18)**:
   - 복잡했던 한국어 전사 확인("맞나요/네/아니요") 및 대안 선택 질문 단계를 전면 폐지.
   - 영어 질문 발화 → 브라우저 내장 Web Speech API 기반 6초 단일 발화 캡처(`continuous = false`, `windowMs = 6000`) → raw top-1 인식 텍스트 직접 AI 1회 평가. 음성 인식 및 음성 합성은 브라우저 내장 기능을 사용하여 Gemini STT/TTS API를 전혀 호출하지 않음 (FOLLOWUP-19 D1 예산 확인 시 STT/TTS 0건 확인).
   - 한국어 1~2문장 원포인트 피드백 + 영문 모범 표현 제공.
   - 완전한 문장(`relevant` + `sentenceComplete: true`)은 1회 연습 완료, 미완성/단답(`Coffee, please` 등)은 의미를 인정하되 2회 연습 후 다음 질문으로 진행.

3. **독립 D1 예산 보호 및 90% 글로벌 하드캡 유지 (FOLLOWUP-19)**:
   - 독립 D1 예산 DB(`CONVERSATION_BUDGET_DB`) 원자적 단일 INSERT 조건문 검사.
   - 공급자(Google AI Studio) 한도 대비 90% 정수 내림 하드캡 엄격 적용:
     - `gemini-3.5-flash-lite`: **13 RPM** / 225,000 안전 단위/분 / **450 RPD**.
   - 기존의 불필요한 개인/IP별 3/분 클램프를 제거하고 정책값 `Math.min(callerRpm, rpm)` 적용.
   - 단일 IP/발신자 17.260초 내 4회 연속 호출 200 OK 통과 확인 (D1 카운트 9 $\rightarrow$ 13 정상 증분 확인).

4. **로컬 분당 한도 페이싱 (Pacing) 및 자동 재시도 (FOLLOWUP-19)**:
   - 로컬 D1 분당 롤링 한도 초과 시 HTTP 429 (`COACH_MINUTE_LIMIT`, `Retry-After: 61`) 응답.
   - 컨트롤러가 직전 사용자 답변을 그대로 보존하면서 61초 카운트다운(`phase: 'waiting'`) 후 최대 2회까지 자동 재시도 (재녹음 없음).
   - 일일 한도(`COACH_DAILY_LIMIT`) 및 업스트림 제공자 오류는 자동 재시도 없이 명확한 한국어 안내 후 안전 중단.

5. **텍스트 전용 학습 모드 구현 및 1차 검증 (FOLLOWUP-20, 배포 대기)**:
   - 텍스트 모드 전환 시 마이크를 요구하거나 무음 타임아웃/예문 폴백을 실행하지 않고, 사용자 텍스트 입력을 abortable 프로미스로 대기(`waitForTextAnswer`).
   - 코칭 시작 전 텍스트 제출 방지 및 입력값 보존 처리.
   - Codex 단위/통합 테스트 66건 통과 및 로컬 Chrome 1차 동작 확인 완료 (최종 전체 검증 및 배포 대기).
