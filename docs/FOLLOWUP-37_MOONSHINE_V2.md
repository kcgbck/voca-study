# FOLLOWUP-37 — Moonshine Voice v2 음성 입력 연결

검증일: 2026-10-26 (KST). 구현: Gemini 구독 CLI. 연결 방식 결정·실행 검증: Codex.

## 적용 범위와 비용

- 일반 AI 회화의 기본 음성 입력을 Chrome Web Speech에서 **Moonshine v2 영어 Small Streaming**으로 교체했다. 별도 시험 주소를 추가하지 않는다.
- 공식 `@moonshine-ai/moonshine-wasm` **0.1.5**, `ModelArch.SmallStreaming = 4`, 영어 모델 `quantized_26_07_30`을 고정했다. 영어 모델과 라이브러리는 MIT 범위이며 API 키·유료 음성 서버가 필요하지 않다.
- 최초 모델 파일 합계는 **165,489,086 bytes**다. 공식 모델 CDN에서 내려받고 브라우저 모델 캐시를 재사용한다. 다운로드·캐시 보관 가능 여부는 네트워크와 브라우저 저장 공간에 영향을 받는다.
- 음성은 기기에서 16kHz 모노로 변환한 뒤 전용 Worker에서 처리한다. 선택한 모델은 Streaming 아키텍처지만, 이번 연결은 기존 **10초 녹음 후 전사** 방식이다. 실시간 스트리밍 입력으로 구현했다고 표시하지 않는다.
- 음성 오디오를 앱 서버나 Google AI로 업로드하지 않는다. 기존과 같이 **인식된 영어 글자**는 답변 평가 시 Google AI로 전송된다. 한국어 안내·피드백과 영어 질문·예문의 브라우저 음성 출력은 유지한다.
- Gemini 대화 모델·서버·독립 예산 DB·90% 한도는 변경하지 않았다. 대화는 13 RPM / 보수적 로컬 예산 225,000 단위 TPM / 450 RPD 상한을 유지한다. 이 단위는 제공사가 측정한 실제 사용량과 구별한다.

공식 근거: [라이선스](https://github.com/moonshine-ai/moonshine/blob/main/LICENSE), [브라우저 SDK](https://github.com/moonshine-ai/moonshine/blob/main/language-bindings/wasm/README.md), [모델 목록](https://moonshine-voice.readthedocs.io/en/stable/models/available-models/). 선택한 영어 모델에 대한 확인이며 다른 언어·TTS 모델의 조건을 동일하다고 가정하지 않는다. 배포에는 공식 저작권·제3자 고지를 `public/licenses/moonshine-voice-0.1.5.txt`에 포함했다.

## 화면과 실행 경계

- 기존 ‘코칭 시작’에서 모델을 먼저 준비한 후 질문을 시작한다. 준비 시간은 10초 답변 시간에 포함하지 않는다. 다운로드 진행·취소·한국어 오류·텍스트 전환을 제공한다.
- 텍스트 모드는 모델 준비·다운로드·마이크를 건너뛴다. Chrome 인식으로 조용히 되돌리는 폴백은 없다. 지원하지 않는 환경에서는 텍스트 모드로 안내한다.
- 연속 시작, 준비 도중 취소·텍스트 전환·화면 이탈·비교 패널 실행 뒤의 늦은 완료가 코칭을 다시 켜지 않도록 세대를 구분한다. 컴포넌트 종료 시 모델 Worker를 해제한다.
- 실제 청취는 10초를 유지한다. 이후에는 ‘기기에서 음성 변환 중’을 구분해 표시한다. 모델 준비는 최대 180초, 추론은 최대 15초, 회화 제어기의 Moonshine 입력 전체 대기는 최대 60초다. 기존 인식기 기본 대기 설정은 유지한다.
- 첫 답변·변경 답변은 AI가 평가하고, 직전에 AI가 승인한 동일 답변 반복만 기존 규칙으로 재사용한다. 정답에 맞춘 단어 치환이나 이름·예문 주입은 하지 않는다.
- 기존 녹음기의 무음 표시만으로 작은 음량을 버리지 않는다. PCM의 길이·유한성·범위와 디지털 무음을 별도 검사한다. 진단 기록은 음성 엔진·모델을 함께 기록하고 이전 기록도 읽는다. 실제 녹음은 진단 기록에 저장하지 않는다.
- WASM 실행에 필요한 COOP/COEP를 앱 정적 응답과 개발·미리보기 서버에 적용했다. SDK 실행 파일 10개는 의존성에서 빌드 시 복사하며 대용량 바이너리와 모델을 Git에 추가하지 않는다.

## 독립 검증 결과

1. **자동 검사:** 타입·린트·88개 파일 / 936개 시험·프로덕션 빌드 통과. 새 시험의 비동기 대기 및 이전 진단 참조 오류를 수정했고, 마지막 공백 오류도 제거했다. 원본: 비배포 `.agy-work/543`, `548`, `550`, `554`, `559` 기록.
2. **단어장 보존:** 1,800개 어휘 / 54,000회 문제 생성 감사에서 결함 0건. 단어 DB, PDF/OCR 소스 및 사용자 저장소는 변경하지 않았다.
3. **실제 엔진 실행:** 공개 JFK 11초 예제를 Node WASM에서 2회 전사(1,030ms / 851ms). Chrome에서는 공식 SDK 1,106ms, 실제 빌드된 Worker와 런타임으로 923ms에 전사했다. 단순 모의 엔진 시험이 아니다.
4. **합성 영어 대조:** coffee/cup, 부정어, thirteen/thirty를 구분했다. 합성 이름 Minjun Park는 Min Jun Park로 전사됐다. 작은 음량 합성 입력도 전사됐으나, 브라우저 첫 시험의 매우 작은 음량에서는 빈 결과가 1회 있었고 재실행에서 성공했다. 이를 안정적인 인식률 수치로 일반화하지 않는다.
5. **실제 학습 제어기:** 실제 Moonshine 전사 2회와 모의 평가기를 연결해 평가 1회·정답 반복 재사용·모델 유지·무음 평가 미실행을 확인했다. 텍스트 모드, 성인 확인 숨김, 일반 화면의 기본 모델 표시도 브라우저에서 확인했다.
6. **실제 운영 평가:** 합성 coffee 문장을 Moonshine으로 2회 전사하고 운영 평가 API로 연결했다. HTTP 200 **1회**, 한국어 피드백·완전한 문장 판정, 동일 정답 반복의 **추가 호출 0회**를 확인했다. 실제 마이크와 음성 출력은 이 시험에서 대체했다. 전사 326ms / 229ms, 운영 HTTP 응답 1,916ms였다. 원본: `.agy-work/557_moonshine_live_result.json`.
7. **실제 예산 DB:** 로컬 음성·브라우저 검증 전후 집계 동일. 위 운영 평가 시험 뒤에는 **대화 +1건 / 로컬 예약 예산 +17,028단위**, STT·TTS 예약은 **0건**이었다. 예산 일자 키는 서버 집계 기준이므로 KST 검증일과 구별한다. 원본: `.agy-work/547`, `556`, `558`.
8. **배포물:** 35개 파일 검사에서 제공된 비밀 문자열 발견 0건, 사용자 APK 미포함. SDK 실행 자산 10개, 모든 파일 25MiB 미만을 확인했다. 배포 고지는 커밋 검사에 맞춰 행 끝 공백만 제거했으며, 이를 제외한 공식 수집본의 내용은 보존했다.

## 실기기에서 남은 확인

**S25 Edge의 실제 마이크·한국인 초보자 발음·한국 이름의 정확도와 지속 사용 시 지연·발열은 미검증이다.** 공개 원어민 예제, 합성 영어, PC 성능을 실제 휴대폰 인식률로 발표하지 않는다. 기존 Chrome 인식보다 낫다는 결론도 실기기 결과 전에는 보류한다.

설치한 앱 또는 정규 주소 `https://voca-study-akf.pages.dev/`를 새로고침한 뒤 AI 회화에서 Moonshine 기본 표시를 확인한다. Wi-Fi에서 최초 모델 준비 후 실제 coffee/cup·이름 문장을 말하고, 틀리면 ‘인식·평가 기록’의 원본·엔진·모델을 복사해 비교한다. 불필요한 인식 확인 대화는 추가하지 않는다.
