## 요청과 범위

사용자가 카페 주문 5~6문항을 Gemini가 구현하고 Codex가 상황별 질문·한국어 교정·승인 답변 반복 재사용·예산 차감을 검증한 뒤 main 커밋·푸시·운영 배포하도록 승인했다. 별도 시험 URL을 추가하지 않고 `https://voca-study-akf.pages.dev/`를 유지한다.

Gemini 구독 CLI가 제품 코드와 관련 시험을 작성하며 Codex가 직접 실행·검토한다. 앱의 대화 모델, 무료 90% 상한(13 RPM / 225,000 로컬 예약 유닛 TPM / 450 RPD), 독립 예산 DB, 단어장과 사용자 저장소는 보존한다. 기본 Web Speech와 Whisper 비교 패널의 선택은 바꾸지 않는다.

## 구현 목표

- 카페 주문의 음료 → 온도 → 크기 → 매장/포장 → 추가 옵션 → 결제 6문항. 음료 답변에 이미 온도를 제시하면 온도 질문을 생략하는 5문항 경로.
- 새 답변에 대한 의미·완성도·한국어 피드백·영어 예문·후속 질문 선택을 기존 단일 AI 호출로 처리한다. 서버 카탈로그의 허용 간선만 인정하며 마지막 결제에서만 종료한다.
- 최근 최대 2턴, 맥락 JSON 1,024 UTF-8 바이트, 요청 본문 4 KiB 제한. 새로운 동적 프롬프트 데이터도 16,384 기본 예약 위에 계량한다.
- 완전한 정답은 1회, 단답·교정은 2회 반복한다. 실제로 승인된 동일 문장 반복만 추가 호출 없이 처리한다. 예문·변경 답변·새 질문은 캐시 정답으로 자동 승격하지 않는다.
- 한국어 안내와 영어 질문, 10초 듣기, 인식 확인 대화 없음, 성인 확인 1회 저장, 반복 완료 후 사용자 ‘다음’ 선택을 유지한다.

## 검증 이력

- 구현 전 예산 DB: 2026-10-24 대화 consumed 73건 / 1,207,464 예약 유닛, 클라우드 STT·TTS 기록 없음. 최초 조회는 OAuth 만료로 실패했고 사용자 재로그인 후 성공했다.
- 서버 초안은 중복 코드로 문법 검사에 실패했다. Gemini에 수정 요청했다. 부정어 충돌 안전 응답에서 적응형 후속 ID가 빠지는 검증 경계도 함께 수정 요청했다.
- 기존 단어장 독립 감사: `npm run worddb:audit` PASS. 1,800개 어휘, 54,000회 문제 생성, 전체 결함 0건.
- Codex 독립 모의 제공사 + 실제 메모리 SQLite 프로브 PASS: 잘못된 시나리오·맥락 1,024바이트 초과·본문 4 KiB 초과는 예약/제공사 0회. 정상 합성 카페 요청은 동적 JSON 643바이트 + 기본 16,384 = 17,027유닛이며, 13회 합계 221,351유닛 후 14번째는 429. 449건을 시드한 일일 시험은 1건만 추가 승인해 총 450건으로 정지. 잘못된 후속 ID·제공사 503은 각 consumed 1건, 제공사 시도 1회. 실제 Google 호출 0회. 프로브의 본문 초과 기대값은 기존 정상 정책인 HTTP 413으로 바로잡았다.
- 제품 전체 시험·브라우저·운영 API·예산 전후 비교와 배포 결과는 아래 최종 결과에 기록한다. 진행 중인 항목을 완료로 간주하지 않는다.
