# FOLLOWUP-23: S25 동일 정답 반복과 음성 인식 확인

2026-10-24. Gemini 잔여 항목 감사, Codex 지시·독립 통합시험·결과 검증. 이번 단계는 시험과 문서 변경이며 제품 재배포는 하지 않는다.

## 휴대폰에서 확인할 순서

1. S25의 **Chrome 앱**에서 [현재 학습 버전](https://voca-study-akf.pages.dev/?voice-check=1&build=20261023-12)을 열고 새로고침한다. `코칭 시작`을 누른다. 성인 확인은 처음에만 필요하다.
2. 이름 질문에 `My name is Alex.`라고 답한다. 첫 답변은 AI가 평가하므로 기다리는 것이 정상이다. 화면의 최종 인식 문장이 실제 발화와 맞는지 본다.
3. 따라 말하기에서도 같은 문장을 말한다. **10초 듣기와 최종 인식 처리가 끝난 뒤**, 추가 AI 분석 대기 없이 피드백과 반복 **1/1 완료**로 넘어가는지 확인한다. 중간에 일시정지하거나 새로 시작하면 기존 정답을 다시 평가하므로 이 시험 중에는 멈추지 않는다.
4. `다음`을 눌러 나이 질문에 `I am twenty-eight years old.`라고 답하고 같은 문장을 반복한다. 나이가 28로 인식되는지, 다른 숫자로 바뀌지 않는지 확인한다. 숫자가 영어 단어 대신 `28`로 표시되는 것 자체는 의미 오류가 아니다.
5. `다음`을 눌러 음료 질문에 `Coffee, please.`라고 답한다. 의미는 알아듣고 한국어로 완전한 문장을 안내하는지 확인한다. 이어서 **화면에 나온 완전한 예문**을 두 번 따라 말한다. 첫 완전 문장은 새 답변이므로 AI 평가가 필요하고, 두 번째 동일 문장은 추가 평가 없이 **2/2 완료**되어야 한다.

`바로 처리`는 듣기 10초를 없애는 뜻이 아니라 **추가 AI 네트워크 대기를 생략**한다는 뜻이다. 동일한 발음을 했어도 최종 인식 텍스트의 대소문자·문장부호·숫자 표기가 바뀌면 현재 구현은 새 답변으로 평가한다. 첫 답변/반복의 최종 텍스트가 실제로 같은데도 긴 AI 분석 대기가 있으면 점검 대상이다. 중간에 움직이는 인식 미리보기는 채점 결과가 아니다.

문제가 있을 때에는 `말한 문장 / 화면에 인식된 문장 / 반복 때 AI 분석 대기가 있었는지`만 우선 알려주면 된다. 진단 원본 전체는 원인을 더 좁혀야 할 때 요청한다. 개발 PC의 모의 음성시험을 실제 S25 발음 정확도 측정으로 간주하지 않는다.
